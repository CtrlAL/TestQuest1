# TestQuest1

Учебный проект: MVC-приложение **HomeLibrary** для хранения книг с рекурсивным
оглавлением и поиском, и библиотека **DuplicateDetection** для поиска дубликатов.

## Требования

- .NET SDK 10
- Docker (для PostgreSQL)

## Быстрый старт

```bash
docker compose up -d db
dotnet run --project HomeLibrary
```

Приложение будет доступно на <http://localhost:5176>.

При первом старте контейнера PostgreSQL автоматически выполняются
`HomeLibrary/Database/001_schema.sql` и `002_functions.sql` — создаётся таблица
`books` и семь хранимых функций `usp_books_*`, через которые работает
репозиторий. Приложение ждёт готовности БД (healthcheck) и падает с понятной
ошибкой, если БД недоступна.

## Демо-данные

В режиме `Development` при старте приложение заполняет пустую таблицу 12
русскими книгами (`HomeLibrary/Models/SeedBooks.cs`). Загрузчик идемпотентен:
если в таблице уже есть хоть одна строка, он ничего не делает, поэтому
повторные запуски не создают дубликаты.

Демо-набор намеренно покрывает крайние случаи — пустое оглавление,
`NULL` в необязательных полях, вложенность до трёх уровней и текст, который
находится только внутри оглавления.

Отключить или включить загрузку явно:

```json
{ "Seeding": { "Enabled": false } }
```

По умолчанию флаг берётся из окружения: в `Development` — включён, в
`Production` — выключен, чтобы вымышленные книги не попали в боевую базу.

## Настройка подключения

Строка подключения по умолчанию — в `HomeLibrary/appsettings.Development.json`.
Порт БД можно переопределить переменной окружения `POSTGRES_PORT`; тогда же
нужно поправить `Port=` в строке подключения.

Учётные данные в `docker-compose.yml` и `appsettings.Development.json`
(`library` / `library_dev`) предназначены только для локальной разработки.

## Сброс базы

Схема применяется только при первом создании тома. Чтобы начать с чистой базы:

```bash
docker compose down -v
docker compose up -d db
```

## Возможности

- Список книг с поиском по названию, автору и тексту оглавления.
- Страница книги с рекурсивным оглавлением.
- Создание и редактирование книги, редактирование оглавления с проверкой XML.
- Удаление книги.

## Сборка

```bash
dotnet build TestQuest1.slnx -c Release
```

## Структура

| Путь | Назначение |
| --- | --- |
| `HomeLibrary/Controllers` | MVC-контроллеры |
| `HomeLibrary/Models` | модели предметной области и формы |
| `HomeLibrary/Views` | Razor-представления |
| `HomeLibrary/Services` | разбор и проверка XML оглавления |
| `HomeLibrary/Data` | репозиторий и загрузчик данных |
| `HomeLibrary/Database` | SQL-схема и хранимые функции |
| `DuplicateDetection` | библиотека поиска дубликатов |
